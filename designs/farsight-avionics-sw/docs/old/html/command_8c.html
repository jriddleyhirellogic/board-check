Executes a TMTC command This executes the command and constructs a response packet to be sent through the serial port. The opcode is extracted from the header information and is used to signal a task through the message queue. The response packet header defaults to that of the request packet. Errors in the response packet only indicate the correctness of the request, as some take a long time to execute.

Parameters
p_HeaderPointer to header structure. This contains the opcode, error code and sequence number
p_u8_DataPointer to the data portion of the received TMTC request packet
p_Response_BufferPointer to buffer where response packet is constructed.
p_u8_Response_LengthPointer to length of response packet
Returns
