uint16_t HW_get_16bit_reg(addr_t reg_addr)

The macro HAL_get_16bit_reg() is used to read the value of a 16 bits wide register.

BASE_ADDR: A variable of type addr_t specifying the base address of the peripheral containing the register. REG_NAME: A string identifying the register to read. These strings are specified in a header file associated with the peripheral. RETURN: This function-like macro returns a uint16_t value.
