\begin{DoxyCompactList}\small\item\em Executes a TMTC command This executes the command and constructs a response packet to be sent through the serial port. The opcode is extracted from the header information and is used to signal a task through the message queue. The response packet header defaults to that of the request packet. Executes a TMTC command This executes the command and constructs a response packet to be sent through the serial port. The opcode is extracted from the header information and is used to signal a task through the message queue. The response packet header defaults to that of the request packet. Errors in the response packet only indicate the correctness of the request, as some take a long time to execute.
