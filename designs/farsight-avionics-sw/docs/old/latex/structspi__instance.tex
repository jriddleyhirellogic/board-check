\doxysubsection{Detailed Description}
There is one instance of this structure for each of the core SPIs. Instances of this structure are used to identify a specific SPI. A pointer to an instance of the \doxylink{core__spi_8h_ac5fac91679b0d1a0d47d793fe8a7d681}{spi\+\_\+instance\+\_\+t} structure is passed as the first parameter to SPI driver functions to identify which SPI should perform the requested operation. \begin{Desc}
