\hypertarget{_2home_2iboard_2farsight_2av_board_workspace_2Camera_2include_2core_spi_8h-example}{}\label{_2home_2iboard_2farsight_2av_board_workspace_2Camera_2include_2core_spi_8h-example}The \doxylink{core__spi_8h_a604018a460cbb77c22a486df479792a0}{SPI\+\_\+init()} function initializes the hardware and data structures of a Core\+SPI instance referenced by this\+\_\+spi parameter. This function must be called for each Core\+SPI instance with a unique this\+\_\+spi and base\+\_\+addr parameter combination. The \doxylink{core__spi_8h_a604018a460cbb77c22a486df479792a0}{SPI\+\_\+init()} function must be called before any other Core\+SPI driver functions are called.

After calling the \doxylink{core__spi_8h_a604018a460cbb77c22a486df479792a0}{SPI\+\_\+init()} the Core\+SPI is configured as a master, all interrupt sources will be masked and all the slaves are deselected.


\begin{DoxyParams}{Parameters}
{\em this\+\_\+spi} & The this\+\_\+spi parameter is a pointer to a \doxylink{core__spi_8h_ac5fac91679b0d1a0d47d793fe8a7d681}{spi\+\_\+instance\+\_\+t} structure that identifies the Core\+SPI hardware block to be initialized. This parameter must point to the g\+\_\+core\+\_\+spi global data structure defined within the application code.\\
\hline
{\em base\+\_\+addr} & The base\+\_\+addr parameter is the base address in the processor\textquotesingle{}s memory map for the registers of the Core\+SPI instance being initialized. It is assumed that any non NULL value passed in here points to a valid instance of a Core\+SPI as the driver has no way of verifying this. Failure to pass in a valid address can result in system instability.\\
\hline
{\em fifo\+\_\+depth} & The fifo\+\_\+depth parameter specifies the number of frames in the receive and transmit FIFOs of the Core\+SPI instance being initialized.\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
This function does not return any value.
\end{DoxyReturn}
