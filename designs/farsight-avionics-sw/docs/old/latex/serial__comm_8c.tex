void v\+\_\+\+UART16550\+\_\+\+Handler (\begin{DoxyParamCaption}\item[{void}]{}{}\end{DoxyParamCaption})}



Interrupt handler for the 16550 type uart. This handles both receive and transmit interrupts. A timer with a timeout of 3 characters is reloaded every time a character is received. Each receive character updates a state machine which parses the packet, extracting the header and data and updating a crc check. When the time expires, the serial\+\_\+comm thread is notified. Note that ill formed messages and garbage data do not result in the notification.
