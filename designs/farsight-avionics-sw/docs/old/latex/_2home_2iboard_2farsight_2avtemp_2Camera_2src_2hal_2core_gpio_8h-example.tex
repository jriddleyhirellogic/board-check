 Note that a Core\+GPIO hardware instance is generated with a fixed configuration for some or all of its IOs as part of the hardware flow. Attempting to modify the configuration of such a hardware-\/configured IO using the \doxylink{avtemp_2Camera_2src_2hal_2core__gpio_8h_a59c399acb6c889d5727d6109fbec85c6}{GPIO\+\_\+config()} function has no effect.

A pointer to the same data structure is used in subsequent calls to the Core\+GPIO driver functions in order to identify the Core\+GPIO instance that must perform the operation implemented by the called driver function.\\
